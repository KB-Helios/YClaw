# NorthBridge Organization Profile

## Organization

- **Name:** NorthBridge
- **Type:** Product and company automation program
- **Stage:** Active engineering
- **Focus:** Private AI workspace, agent interoperability, and auditable automation

## Products and Systems

- **NorthBridge-Chat:** multi-provider conversational workspace and operator surface.
- **NorthBridge YClaw fork:** department-based company automation control plane.
- **A2A backbone:** standard discovery, authenticated task transports, durable state,
  local and remote fan-out, artifact capture, cancellation, and synthesis.

## Differentiators

1. Open cross-framework interoperability instead of a single-provider agent silo.
2. Durable operator-scoped work with explicit authority and audit trails.
3. Connected product, engineering, operations, support, finance, and growth workflows.
4. Honest separation of automated verification, deployed runtime proof, and manual acceptance.

## Technology

TypeScript, Express, React, official A2A JavaScript SDK, MongoDB, PostgreSQL, Redis,
AWS ECS Fargate, Docker Compose, GitHub, and pluggable LLM providers.
